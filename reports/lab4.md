# Problems
## Problem 01

在我们的easy-fs中，root inode起着什么作用？如果root inode中的内容损坏了，会发生什么？

**My Answer**

---

root inode起到了索引其下所有文件的root inode的作用，正是因为我们能够通过root inode找到保存文件名和inode id的地方，才能够索引到下面的文件的disk inode，进而获取inode。

## Problem 02 (ch7 Problem 01)

举出使用 pipe 的一个实际应用的例子。

tips:

想想你平时咋使用 linux terminal 的？

如何使用 cat 和 wc 完成一个文件的行数统计？

**My Answer**

---

Linux shell脚本中的管道符号就是使用pipe的例子，如我们需要查找一个目录下所有以`.json`作为后缀的文件，可通过：

```shell
find <your directory> | grep '\\.json$'
```

完成查找，它相当于是将`find`命令的执行结果作为标准输入传送给`grep`命令。

## Problem 03 (ch7 Problem 02)

如果需要在多个进程间互相通信，则需要为每一对进程建立一个管道，非常繁琐，请设计一个更易用的多进程通信机制。

**My Answer**

---

可以通过中心化的方式减少管道的建立，如使用一个虚拟文件作为管道中心，所有进程建立管道时实际上直接建立的是通向该虚拟文件的管道，再由该虚拟管道对IO进行调度。
